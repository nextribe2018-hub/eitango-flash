# 英単語フラッシュ

30語を1分で覚えて、1分でテストする英単語アプリ（Expo / React Native）。

- 13パック×300語：TOEIC 500〜900／高校受験 最難関・大学受験 難関／金融・医療・半導体・AI・IT・コンサル。TOEIC 500 は無料、ほかはパックごとの買い切り（最初の30語はお試し）
- 正解で+0.5秒、得点＝残り秒＋正解数。300語ごとの定着テストと、全パック横断の総合定着テスト
- 記録は端末内のみ（ログイン・外部送信なし）

```bash
npm install
npx expo start
npm test && npm run typecheck
```

詳細は `docs/HANDOFF.md`。
